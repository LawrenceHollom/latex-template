# latex-template
A default LaTeX project for importing to Overleaf, with header file and default structure of stuffs.

This should be updated from time to time, and in every instance of making a new Overleaf project, 
pulled in and worked on, with any changes filtering back to the main version which lives here.

There are a collection of files which give a blank project, and a couple of strange files:
- dark-mode.tex will, if imported, change the document to white text on a dark background, and will label theorems etc. in the pdf.
- response.tex contains a template of a response to reviewers.
